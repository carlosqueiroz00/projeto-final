# Grão & Prosa ☕

Site de uma cafeteria fictícia, feito como Projeto Final da disciplina **Desenvolvimento Front-end (ADS-02N)**.

O layout segue o protótipo criado no Figma no 1º bimestre.

## Páginas

- **Home** (`index.html`): destaque principal e os diferenciais da cafeteria.
- **Cardápio** (`cardapio.html`): produtos com preço e botão de pedido.
- **Contato** (`contato.html`): endereço, horário, formulário e mapa.

## Tecnologias

- **HTML5** com tags semânticas (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, `address`)
- **CSS3** com variáveis, Flexbox, Grid e media queries (layout responsivo para celular, tablet e computador)
- **JavaScript** puro, sem bibliotecas

## Funcionalidades em JavaScript

1. **Menu hambúrguer**: abre e fecha o menu no celular.
2. **Pedido no cardápio**: o botão "Pedir" soma os itens e o valor total, com opção de limpar.
3. **Aviso na tela**: mensagem rápida confirmando cada ação.
4. **Status de funcionamento**: mostra "Aberto agora" ou "Fechado agora" conforme o dia e a hora.
5. **Validação do formulário**: confere nome, e-mail e mensagem e mostra os erros embaixo de cada campo.
